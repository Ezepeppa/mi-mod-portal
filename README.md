# Mod Sub-Grid & Off-Grid Micro-Architecture v4.0.0 (Minecraft 1.20.1 Fabric)

Arquitectura v4.0.0 con Mixins (`subgridmod.mixins.json`), BlockEntities nativos reales (libro flotante animado en Mesa de Encantamientos, hornos que cocinan, cofres animados), Puente de Mundo Virtual (`SubGridWorldContext`), contorno negro rotado con `RenderLayer.getLines()` + `WorldRenderer.drawBox`, prevención de solapamiento visual OBB SAT y compatibilidad directa con el Mod de Portales y Gravity Gun.
